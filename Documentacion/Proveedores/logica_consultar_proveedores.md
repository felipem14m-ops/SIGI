# Consultar Proveedores

La lógica de esta funcionalidad se maneja principalmente desde la vista auth/Adminproveedores.php.

Para realizar esta acción, el usuario simplemente accede al módulo de proveedores desde el menú lateral del sistema. La vista se encarga automáticamente de cargar y mostrar todos los proveedores registrados en el sistema. Al momento de cargar la página, la vista ejecuta consultas al modelo Proveedor.php llamando al método listarTodos que trae todos los proveedores con información adicional calculada.

El modelo Proveedor.php ejecuta una consulta SQL de tipo SELECT con LEFT JOIN y GROUP BY para traer los proveedores junto con un conteo de cuántos productos tiene asignados cada uno. La consulta cuenta solo los productos que no están en estado inactivo para dar una cifra más precisa de productos realmente disponibles de ese proveedor. Se usa LEFT JOIN para que los proveedores sin productos también aparezcan en el listado con un conteo de cero. La consulta trae todos los campos del proveedor: ID, nombre, teléfono, email, empresa, estado activo y fecha de registro. Los resultados se ordenan alfabéticamente por nombre de proveedor para facilitar la búsqueda visual.

Una vez que los datos llegan a la vista, se renderizan en una tabla HTML que muestra columnas para nombre del proveedor en negrita, teléfono con formato de enlace clickeable si existe, email con formato de enlace mailto si existe, empresa o razón social, cantidad de productos asignados con un badge que muestra el número, fecha de registro en formato legible, estado con badge de color verde si está activo o gris si está inactivo, y botones de acciones para editar y desactivar o activar. Si algún campo opcional como teléfono, email o empresa está vacío, se muestra un guion o texto indicando que no está disponible.

La tabla utiliza la librería DataTables de JavaScript que se inicializa automáticamente al cargar la página y proporciona funcionalidades avanzadas. DataTables agrega un campo de búsqueda global que permite buscar en tiempo real por nombre, teléfono, email o empresa del proveedor. También permite ordenar los datos haciendo clic en los encabezados de las columnas, siendo útil ordenar por nombre, por cantidad de productos o por fecha de registro. La paginación se maneja automáticamente mostrando un número configurable de registros por página. En dispositivos móviles, DataTables adapta la tabla para que sea responsive.

Desde esta tabla el usuario puede realizar varias acciones. Al hacer clic en el botón de editar, se ejecuta una función JavaScript que busca los datos del proveedor en el array JSON cargado en la página, prellena el modal de edición y lo muestra. Al hacer clic en desactivar, muestra un diálogo de confirmación y luego redirige al controlador con la acción de desactivar. No hay restricción de desactivar proveedores con productos asignados, a diferencia de las categorías, porque la relación producto-proveedor es opcional.

Es importante mencionar que el conteo de productos se calcula en tiempo real cada vez que se carga la página, por lo que siempre muestra información actualizada. Los proveedores son útiles para llevar control de dónde vienen los productos, gestionar relaciones comerciales, y generar reportes de compras por proveedor. Aunque el campo proveedor es opcional en los productos, es una buena práctica mantener esta información actualizada para tener trazabilidad completa del inventario.
