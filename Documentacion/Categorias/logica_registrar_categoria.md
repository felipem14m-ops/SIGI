# Registrar Categoría

La lógica de esta funcionalidad se maneja principalmente desde la vista auth/Admincategorias.php.

Para realizar esta acción, el usuario interactúa con el botón "Nueva Categoría" que abre un modal con el formulario. El javascript de la página se encarga de mostrar el modal con los campos necesarios: nombre de la categoría que es obligatorio con un máximo de 80 caracteres, descripción opcional para agregar detalles sobre la categoría, y un campo de archivo opcional para subir una imagen representativa de la categoría en formatos JPG PNG o WEBP.

Al momento de enviar los datos, el formulario en su atributo action está conectado directamente con el archivo CategoriaController.php con el parámetro accion=crear. Dentro de este controlador, el sistema pasa por la acción o función llamada crear en función principal.

Cabe recordar que este controlador incluye todos los archivos de configuración como database.php para tener permisos en la base de datos, y se apoya en el modelo Categoria.php necesario para interactuar con la tabla categorias. Una vez que el controlador valida los datos recibidos del formulario, verifica que el nombre no esté vacío ya que es el único campo obligatorio. Si el usuario subió una imagen, el controlador valida que sea un formato permitido JPG PNG o WEBP, que no supere los 2MB de tamaño, genera un nombre único con el prefijo cat_ seguido de un identificador único para evitar colisiones y la mueve a la carpeta IMG/categorias. Después de todas estas validaciones, el controlador llama al método crear del modelo pasándole todos los datos saneados.

El modelo Categoria.php recibe los datos y aplica la función ucfirst al nombre para capitalizar la primera letra automáticamente. Antes de insertar, el modelo prepara una consulta SQL de tipo INSERT con los campos nombre, descripcion, imagen y activa usando consultas preparadas con PDO para prevenir inyección SQL. La consulta inserta la nueva categoría en la tabla categorias estableciendo el campo activa en 1 por defecto, lo que significa que la categoría estará disponible inmediatamente para ser asignada a productos. Si el nombre de la categoría ya existe en la base de datos, MySQL retorna un error con código 23000 debido al constraint UNIQUE en el campo nombre, y el modelo captura este error específico para retornar un mensaje amigable indicando que ya existe una categoría con ese nombre.

Al finalizar el proceso con éxito o si ocurre algún error, el mismo controlador se encarga de hacer el redireccionamiento para devolver al usuario a la vista auth/Admincategorias.php, mostrando un mensaje flotante con SweetAlert2 indicando si la categoría fue registrada correctamente o si hubo algún error en el proceso. Una vez creada, la categoría aparece inmediatamente en los selects de formularios de productos y en la tabla de gestión de categorías.
