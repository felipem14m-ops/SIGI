# Consultar Ventas

La lógica de esta funcionalidad se maneja principalmente desde la vista auth/Adminhistorialventas.php para administradores que ven todas las ventas, o desde auth/misventas.php para empleados que solo ven sus propias ventas.

Para realizar esta acción, el usuario simplemente accede al módulo de historial de ventas desde el menú lateral del sistema. La vista se encarga automáticamente de cargar y mostrar todas las ventas registradas aplicando filtros según el rol del usuario. Al momento de cargar la página, la vista ejecuta consultas al modelo Venta.php llamando al método listarVentas que puede recibir parámetros opcionales para filtrar por fecha, por nombre de usuario o por ID de usuario específico.

El modelo Venta.php ejecuta una consulta SQL de tipo SELECT con múltiples JOIN para traer las ventas junto con información relacionada. La consulta hace JOIN con la tabla usuarios para obtener el nombre del cajero que realizó la venta, JOIN con la tabla metodos_pago para obtener el nombre del método de pago utilizado, y una subconsulta que suma las cantidades de la tabla detalleventa para mostrar el total de items vendidos en cada venta. La consulta puede incluir condiciones WHERE opcionales: si se proporciona una fecha filtra por DATE de fecha_venta, si se proporciona un nombre de usuario filtra con LIKE para búsquedas parciales, y si se proporciona un ID de usuario específico filtra exactamente por ese usuario lo cual se usa en la vista de empleados para que solo vean sus propias ventas. Los resultados se ordenan por fecha_venta en orden descendente para mostrar las ventas más recientes primero.

Una vez que los datos llegan a la vista, se renderizan en una tabla HTML que muestra columnas para número de venta con un badge, fecha y hora de la venta en formato legible, nombre del cajero que la realizó, método de pago utilizado, cantidad total de items vendidos, monto total de la venta en formato de moneda colombiana con separadores de miles, estado de la venta con badge verde si está completada o rojo si está anulada, y botones de acciones para ver el detalle completo de la venta. Cada fila de la tabla representa una venta individual con toda su información resumida.

La tabla utiliza la librería DataTables de JavaScript que se inicializa automáticamente al cargar la página y proporciona funcionalidades avanzadas. DataTables agrega un campo de búsqueda global que permite buscar en tiempo real por cualquier campo visible como número de venta, nombre del cajero, método de pago o fecha. También permite ordenar los datos haciendo clic en los encabezados de las columnas, siendo especialmente útil ordenar por fecha o por monto total. La paginación se maneja automáticamente mostrando un número configurable de registros por página con botones de navegación. En dispositivos móviles, DataTables adapta la tabla para que sea responsive colapsando columnas menos importantes.

Adicionalmente, la vista puede incluir filtros personalizados en la parte superior de la tabla que permiten al usuario seleccionar un rango de fechas específico o buscar por nombre de cajero. Estos filtros se envían como parámetros al modelo para que la consulta SQL ya traiga los datos filtrados desde la base de datos en lugar de filtrar en el cliente. Esto es más eficiente especialmente cuando hay muchas ventas registradas.

Desde esta tabla el usuario puede hacer clic en el botón de ver detalle que abre un modal o redirige a otra vista mostrando el desglose completo de la venta con todos los productos vendidos, sus cantidades, precios unitarios y subtotales. Esta información se obtiene llamando a los métodos obtenerCabeceraVenta y obtenerDetalleVenta del modelo que traen la información de las tablas venta y detalleventa respectivamente.

El módulo también puede incluir un resumen estadístico en la parte superior mostrando el total de ventas del día y el total de ingresos del día, información que se obtiene llamando al método resumenDiario del modelo que ejecuta una consulta con COUNT y SUM filtrando por la fecha actual. Para empleados, este resumen muestra solo sus propias ventas del día, mientras que para administradores muestra el consolidado de todos los cajeros.
