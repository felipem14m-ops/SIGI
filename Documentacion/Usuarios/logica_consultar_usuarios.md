# Consultar Usuarios

La lógica de esta funcionalidad se maneja principalmente desde la vista auth/Adminusuarios.php.

Para realizar esta acción, el usuario administrador simplemente accede al módulo de usuarios desde el menú lateral del sistema. La vista se encarga automáticamente de cargar y mostrar todos los usuarios registrados en el sistema. Al momento de cargar la página, la vista ejecuta consultas al modelo Usuario.php llamando al método listarTodos que trae todos los usuarios con su información completa incluyendo datos del rol asignado.

El modelo Usuario.php ejecuta una consulta SQL de tipo SELECT con JOIN para traer los usuarios junto con el nombre de su rol. La consulta hace JOIN con la tabla roles para obtener el nombre descriptivo del rol en lugar de solo mostrar el ID numérico. La consulta trae todos los campos relevantes del usuario: ID, nombre completo, número de identificación, email, rol con su nombre, estado activo o inactivo, intentos fallidos de login, fecha hasta la cual está bloqueado si aplica, y fecha de creación de la cuenta. Los resultados se ordenan por fecha de creación en orden descendente para mostrar los usuarios más recientes primero, o pueden ordenarse alfabéticamente por nombre.

Una vez que los datos llegan a la vista, se renderizan en una tabla HTML que muestra columnas para nombre del usuario en negrita, número de identificación, email con formato de enlace mailto, rol con badge de color azul para administrador y verde para empleado, estado con badge verde si está activo o gris si está inactivo, fecha de creación en formato legible, y botones de acciones para editar y desactivar o activar. Si el usuario tiene intentos fallidos de login mayores a cero, se puede mostrar un indicador de advertencia. Si el usuario está bloqueado temporalmente, se muestra un badge rojo con la fecha hasta la cual está bloqueado.

La tabla utiliza la librería DataTables de JavaScript que se inicializa automáticamente al cargar la página y proporciona funcionalidades avanzadas. DataTables agrega un campo de búsqueda global que permite buscar en tiempo real por nombre, identificación, email o rol del usuario. También permite ordenar los datos haciendo clic en los encabezados de las columnas, siendo útil ordenar por nombre, por rol o por fecha de creación. La paginación se maneja automáticamente mostrando un número configurable de registros por página. En dispositivos móviles, DataTables adapta la tabla para que sea responsive.

Desde esta tabla el administrador puede realizar varias acciones. Al hacer clic en el botón de editar, se ejecuta una función JavaScript que busca los datos del usuario en el array JSON cargado en la página, prellena el modal de edición y lo muestra. Al hacer clic en desactivar, el sistema valida que no sea el propio usuario administrador en sesión, muestra un diálogo de confirmación y luego redirige al controlador con la acción de desactivar. El sistema no permite que un administrador se desactive a sí mismo para evitar quedar bloqueado del sistema.

La vista puede incluir filtros adicionales en la parte superior para filtrar por rol mostrando solo administradores o solo empleados, o para filtrar por estado mostrando solo usuarios activos o solo usuarios inactivos. Esto facilita la gestión cuando hay muchos usuarios registrados.

Es importante mencionar que por seguridad las contraseñas nunca se muestran en esta vista ni en ninguna parte del sistema. Las contraseñas están hasheadas en la base de datos y no se pueden recuperar, solo se pueden cambiar. Si un usuario olvida su contraseña, el administrador debe asignarle una nueva contraseña temporal que el usuario deberá cambiar en su primer login.

El módulo de usuarios es crítico para la seguridad del sistema ya que controla quién tiene acceso y qué permisos tiene cada persona. Solo los administradores pueden acceder a este módulo. Los empleados no pueden ver, crear, editar ni desactivar usuarios. Esto garantiza que solo personal autorizado pueda gestionar las cuentas del sistema.
