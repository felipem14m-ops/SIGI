# Consultar Kardex de Producto

La lógica de esta funcionalidad se maneja principalmente desde la vista auth/Admininventario.php.

Para realizar esta acción, el usuario interactúa con el botón de ver kardex que se encuentra en cada fila de la tabla de productos, o puede seleccionar un producto desde un select para ver su historial completo de movimientos. El javascript de la página se encarga de capturar el ID del producto seleccionado y abrir un modal o sección que muestra el kardex completo.

Al momento de solicitar el kardex, el javascript puede hacer una petición AJAX al archivo InventarioController.php con el parámetro accion=kardex e id del producto, o la vista puede cargar directamente los datos al renderizar la página. Dentro de este controlador, el sistema pasa por la acción o función llamada kardex en función principal.

Cabe recordar que este controlador incluye todos los archivos de configuración como database.php para tener permisos en la base de datos, y se apoya en el modelo Inventario.php necesario para interactuar con la tabla movimiento_inventario. El controlador valida que el ID del producto sea válido y luego llama al método obtenerKardex del modelo pasándole el ID del producto.

El modelo Inventario.php ejecuta una consulta SQL de tipo SELECT con múltiples JOIN para traer todos los movimientos del producto con información completa. La consulta hace JOIN con la tabla tipos_movimiento para obtener el nombre del tipo de movimiento y su signo, JOIN con la tabla usuarios para obtener el nombre del usuario que realizó el movimiento, y opcionalmente JOIN con la tabla venta si el movimiento fue automático por una venta para mostrar el número de venta. La consulta trae todos los campos relevantes: fecha y hora del movimiento, tipo de movimiento con su nombre descriptivo, cantidad movida, stock anterior antes del movimiento, stock resultante después del movimiento, origen que indica si fue manual o automático, motivo que explica por qué se hizo el movimiento, y nombre del usuario responsable. Los resultados se ordenan por fecha en orden descendente para mostrar los movimientos más recientes primero.

Una vez que los datos llegan a la vista, se renderizan en una tabla HTML que muestra cada movimiento como una fila con todas sus columnas. La tabla puede usar colores diferentes para distinguir visualmente entre entradas que suman stock mostradas en verde y salidas que restan stock mostradas en rojo. También puede mostrar íconos diferentes según el tipo de movimiento: flecha arriba para entradas, flecha abajo para salidas, herramienta para ajustes. Si el movimiento fue automático por una venta, se muestra un enlace al detalle de esa venta. Si fue manual, se muestra el motivo completo proporcionado por el usuario.

La tabla del kardex puede utilizar DataTables para proporcionar búsqueda y filtrado, permitiendo al usuario buscar por fecha, tipo de movimiento o usuario. También puede incluir filtros de rango de fechas en la parte superior para ver solo los movimientos de un período específico. Esto es útil para auditorías o para entender qué pasó con el stock en un momento determinado.

El kardex es fundamental para la trazabilidad del inventario ya que registra absolutamente todos los cambios en el stock de cada producto. Cada entrada, cada salida, cada ajuste queda registrado con fecha, hora, usuario responsable y motivo. Esto permite detectar errores, identificar pérdidas, justificar diferencias de inventario y cumplir con requisitos de auditoría. Los movimientos automáticos por ventas se registran con el número de venta para poder rastrear exactamente qué venta causó cada salida de stock. Los movimientos manuales requieren un motivo obligatorio para documentar por qué se hizo el ajuste.

Es importante mencionar que los registros del kardex nunca se eliminan ni se modifican, son inmutables para mantener la integridad del historial. Si se cometió un error en un movimiento, se debe hacer un movimiento contrario para corregirlo, no eliminar el movimiento original. Esto garantiza que siempre haya un rastro completo de todo lo que ha pasado con el inventario.
