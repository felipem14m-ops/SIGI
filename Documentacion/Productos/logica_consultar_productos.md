# Consultar Productos

La lógica de esta funcionalidad se maneja principalmente desde la vista auth/Adminproductos.php.

Para realizar esta acción, el usuario simplemente accede al módulo de productos desde el menú lateral del sistema. La vista se encarga automáticamente de cargar y mostrar todos los productos registrados en el sistema. Al momento de cargar la página, la vista ejecuta consultas al modelo Producto.php llamando al método listarTodos que trae todos los productos con su información completa incluyendo datos de las tablas relacionadas como categorías y proveedores.

El modelo Producto.php ejecuta una consulta SQL de tipo SELECT con LEFT JOIN para traer los productos junto con el nombre de su categoría y el nombre de su proveedor. Se usa LEFT JOIN en lugar de INNER JOIN para que los productos sin categoría o sin proveedor asignado también aparezcan en el listado. La consulta trae todos los campos del producto: ID, código único, nombre, descripción, categoría, proveedor, precios de costo y venta, stock actual, stock mínimo, fecha de creación, fecha de vencimiento, estado e imagen. Los resultados se ordenan alfabéticamente por nombre de producto para facilitar la búsqueda visual.

Una vez que los datos llegan a la vista, se renderizan en una tabla HTML que muestra columnas para imagen del producto en miniatura de 50x50 píxeles, código único en un badge, nombre en negrita, categoría, proveedor, precio de costo, precio de venta en verde, stock actual con alerta visual si está bajo, stock mínimo, estado con badge de color según sea activo verde inactivo gris o agotado rojo, y botones de acciones para editar y desactivar o activar. Si el stock actual es menor o igual al stock mínimo, se muestra un badge rojo parpadeante con ícono de alerta para llamar la atención del administrador sobre productos con stock crítico.

La tabla utiliza la librería DataTables de JavaScript que se inicializa automáticamente al cargar la página y proporciona funcionalidades avanzadas sin necesidad de recargar. DataTables agrega un campo de búsqueda global en la parte superior derecha que permite buscar en tiempo real en todas las columnas visibles de la tabla. También permite ordenar los datos haciendo clic en los encabezados de las columnas, mostrando flechas indicadoras del orden actual. La paginación se maneja automáticamente mostrando 25 registros por página con botones para navegar entre páginas y un selector para cambiar la cantidad de registros por página. En dispositivos móviles, DataTables colapsa automáticamente las columnas menos importantes y agrega un botón de expansión para ver todos los datos.

Desde esta tabla el usuario puede realizar varias acciones. Al hacer clic en el botón de editar, se ejecuta una función JavaScript que busca los datos del producto en el array JSON cargado en la página, prellena el modal de edición y lo muestra. Al hacer clic en desactivar o activar, se muestra un diálogo de confirmación y luego redirige al controlador con la acción correspondiente. La búsqueda de DataTables es case-insensitive, es decir no distingue entre mayúsculas y minúsculas, y busca coincidencias parciales en el texto visible de la tabla.

Es importante mencionar que los datos se cargan una sola vez al abrir la página, por lo que si otro usuario realiza cambios en los productos, estos no se reflejarán automáticamente hasta que se recargue la página con F5. Para catálogos muy grandes con más de 10000 productos, se podría considerar implementar paginación del lado del servidor para mejorar el rendimiento, pero para la mayoría de los casos la paginación del cliente con DataTables es suficiente y más rápida.
